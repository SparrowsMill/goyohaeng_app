# 앱 음식 카탈로그

`lib/data/food_catalog.dart`의 `FoodCatalog.assets`가 앱의 음식 범위와 음식 이미지 매핑의 단일 기준이다. 현재 공통 음식 15종과 수도권 음식 4종을 등록한다. 서버가 다른 지역 음식을 반환해도 앱 카탈로그에는 자동 추가하지 않는다.

- 음식 목록, 내 음식 목록, 재료 상세의 사용 음식은 API 서비스에서 카탈로그에 등록된 항목만 반환한다.
- 음식 상세, 히스토리, 요리 요청도 등록 여부를 확인한다. 범위 밖 음식의 요리 POST는 보내지 않는다.
- 도감, 재료가방 추천, 내 음식 보기, 발자국 음식 선택 화면에서 별도의 지역 필터를 만들지 않는다.
- 난이도·제작 가능 여부·재료 보유량은 카탈로그 내 음식에 적용하는 표시 조건이다.
- `RewardImage`는 미등록 음식의 로컬·네트워크 이미지를 요청하지 않는다. `pubspec.yaml`에는 등록된 19종의 음식 PNG만 개별 등록한다.
- 기존 서버 음식/제작 기록과 원본 PNG 파일은 삭제하지 않는다. 내 음식 목록은 등록 항목만으로 페이지와 총 개수를 다시 계산한다.

음식을 추가하려면 `FoodCatalog.assets`와 `pubspec.yaml`을 함께 수정한다. 서버 음식명과 등록명이 정확히 같아야 한다. `test/food_catalog_services_test.dart`가 매핑·번들 에셋 일치와 서비스 경계를 검사한다.
